# Wine Collection Manager

A Flutter mobile application for managing wine collections across multiple storage locations with automatic label recognition and inventory tracking.

## Features

### MVP (Core Features)

- User authentication with Firebase Auth
- Multiple warehouse management
- Manual wine entry and inventory tracking
- Basic search and filtering
- Simple consumption tracking

### Enhanced Features (Post-MVP)

- Camera-based wine entry with ML Kit text recognition
- Advanced search and filtering by multiple criteria
- Real-time low stock alerts and notifications
- Detailed consumption analytics and history
- Photo storage for wine bottles and labels

## Tech Stack

- **Frontend**: Flutter (Dart)
- **Backend**: Firebase (Auth, Firestore, Storage, Functions)
- **Machine Learning**: Google ML Kit Text Recognition
- **State Management**: Flutter Bloc
- **Testing**: Flutter Test, Mockito, Bloc Test
